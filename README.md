# HemrajRamdath

Website for **caribrands.ca**: Hemraj Ramdath, author of *Beyond Indentureship: Indo-Trinidadian Entrepreneurs*.

Plain HTML + JavaScript, styled with Tailwind CSS v4.

## Structure

| Path | Purpose |
|---|---|
| `site/` | The deployable website (upload this folder only) |
| `src/styles.css` | Tailwind source: design tokens and custom utilities |
| `site/assets/css/styles.css` | Generated by the build; do not edit by hand |
| `archive/` | Previous design versions (not deployed) |
| `HANDOFF.md` | Audit, change log, pending client approvals, deployment and email setup |
| `caribrands site.html`, `*.jpeg` | Original reference page and source photos |

## Build

```bash
npm install
npm run build   # minified CSS
npm run dev     # watch mode while editing
```

Run `npm run build` after any change to `site/index.html` or `src/styles.css`.
